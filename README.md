Occurance of a word 

Step 1: Initialize the input string
Step 2: Declare the method countLetter(inputString).
Step 3: Inside the countLetter() function, Create the HashMap named letterCounts of type
Integer to store the counts of each letter.
Step 4: Convert the input string either to uppercase or lowercase to make it case-
insensitive.
Step 5: Iterate through the characters of the string.
Step 6: Check if the character is a letter and if it is true Increment the count of the letter in the
HashMap.
Step 7: Display the count of each letters in the input string.
